# Claude Code instructions
Read AGENTS.md, config/tools.json, docs/PROJECT_PLAN.md and docs/SECURITY.md first. Build in small tested increments. Never imply a candidate tool is verified or installed. Never silently enable tools. Use Next.js App Router, TypeScript, Tailwind, Supabase Postgres/Auth/Storage, row-level security, a server-side tool gateway, and separate durable workers. Never expose service-role keys in browser code. Enforce human approval for crawling, external writes, security scans, login automation, spending, publishing, and production deployment. Save source URL, fetched_at, license/permission evidence and content hash with every source. Use a queue with retries, idempotency and cost limits. Generate migrations and tests, request approval before applying to production.
