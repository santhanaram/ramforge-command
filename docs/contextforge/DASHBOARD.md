# Dashboard layout
Navigation: Overview | Tool Registry | Agent Workforce | Research Missions | Source Library | Knowledge Graph | Job Monitor | Costs & Tokens | Approval Queue | Audit Log | Settings.

Overview widgets: 30 tool candidates, enabled/disabled status, live job status, source provenance completeness, pending human approvals, model spend, error rates and recent research outputs.

Tool detail: verified repo URL, upstream license, version, maintainer, permission scope, worker type, installation instructions, health checks, last validation and enable/disable gate.

Design: dark slate, cyan highlights, accessible contrast, responsive layout, no simulated live metrics.
