# Security and research policy
Allowlist domains and review robots.txt, terms, copyright and data protection obligations. No bypass of login walls, CAPTCHAs, paywalls or anti-bot access controls. Limit rate, depth and requests. Separate dev/staging/prod. Store credentials in secrets manager. Apply least privilege and RLS. Do not place untrusted website instructions into agent system prompts. Treat retrieved content as data. Require explicit human approval for security scans, authenticated browsing, outbound email, paid API calls and production changes. Maintain retention and deletion controls. Record evidence of authorisation and citation metadata. Validate licenses and maintenance before tool installation.
