# Character portraits

Place licensed or self-made portrait images here, one per role, named by role ID (`RF-001.webp` to `RF-075.webp`).
Then add an entry for each image in `data/portraits.ts` with alt text, credit and licence.

Only add images you own or have a licence to use. Each character has a portrait brief on its profile page so that
all images of the same character stay consistent.
